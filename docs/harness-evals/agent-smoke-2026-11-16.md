# Agent role smoke evaluation — 2026-11-16

Historical snapshot. The fresh native Codex continuation is reported in [agent-eval-codex-2026-11-17.md](agent-eval-codex-2026-11-17.md); it supersedes the host/recertification limits below only in its explicitly tested scope.

Six synthetic cases, two independent fresh subagent sessions per case (12 total). Each session received only a neutral directory's brief, subject and runnable probe plus the canonical role instructions. Answer keys were not included. No role prompt was tuned against these cases. Reviewer cases exercise discarded child failure and a clean implementation; verifier cases exercise missing required Docker and a clean synthetic report; auditor cases exercise unreachable and reachable commits.

All 12 verdicts matched the key, with no defect reported in the clean cases. After T08 changed verifier/auditor guidance, the old results were rejected and those eight trials were repeated. Two repeats used new sessions; six used idle agents previously exposed only to a different role/case because the host reached its agent-thread limit. They received no answer key, but these six repeats are not fresh-context trials. Reviewer guidance was unchanged. The root replayed each probe, compared actual JSON output with the observation, and checked fixture bytes plus the role SHA-256 recorded on each trial against both the manifest and current instructions. Preparing a new manifest cannot certify old trial hashes. A mismatched role/source/probe is UNVERIFIED, never PASS.

Commands: `node --test scripts/harness/eval-agents.test.mjs`; `node scripts/harness/eval-agents.mjs --validate`; `--prepare`; then `--import backend/target/harness-evidence/agent-trials.json`. Native subagent dispatch is deliberate: the installed Codex CLI cannot decode the model list and Claude CLI is not authenticated. Probe/manifest/trials are ignored evidence under backend/target/harness-evidence/; no external API credentials or teacher data are involved.

**Limits:** this is a small role-instruction smoke, not a rerun of historical A1/A2 or a measurement of general code-review accuracy. The host inherited the session model; exact model variant/usage was not exposed by the tool. No different-family judge ran. Deterministic probe replay is the independent check, not a claim of cross-model judging. All roles remain supervised; no merge/deploy authority is granted. New hard/held-out cases are required before increasing autonomy.
